# Mi Tiendita

App para la tiendita de una primaria: cobro, pedidos, fiado, ganancias y cierre del día. Funciona sin internet y los datos se guardan solo en el celular.

Para instalarla, abre la página en Chrome (Android) → menú ⋮ → **Instalar app**.

Guía rápida para imprimir: `docs/guia-rapida.html`.
